Hubble Tension Route Map 2026

An educational route map to observational probes, theoretical routes, and constraints in the Hubble tension.

ハッブルテンション現在地マップ：物理学初学者のための観測プローブ・理論ルート・制約百科

Claim Boundary

  • This project does not claim to solve the Hubble tension.
  • This project does not propose a new cosmological model.
  • This project does not claim that ΛCDM has collapsed.
  • This project does not present an expert-reviewed cosmological conclusion.
  • This project is an educational route map for beginners and interested readers.

Central Thesis

The difficulty of the Hubble tension is not merely to move H0. The difficulty is to move H0 while preserving consistency with CMB, BAO, SNe Ia, distance ladders, S8, and structure formation.
