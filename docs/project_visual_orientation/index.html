Hubble Tension Route Map

An educational reference guide to observational probes, theoretical routes, and constraints.

ハッブルテンション現在地マップ：物理学初学者のための観測プローブ・理論ルート・制約百科

Claim Boundary

  • This project does not claim to solve the Hubble tension.
  • This project does not propose a new cosmological model.
  • This project is not an expert-reviewed cosmological conclusion.
  • This project is an educational route map.

Central Thesis

The difficulty of the Hubble tension is not merely to move H0. The difficulty is to move H0 while preserving consistency with CMB, BAO, SNe Ia, distance ladders, S8, and structure formation.
