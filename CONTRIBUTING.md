# Contributing / Correction Guide

## What kinds of feedback are most valuable?

This project especially welcomes corrections on:

- factual errors in cosmology;
- outdated observational status;
- missing or better references;
- misleading simplifications;
- citation placement;
- terminology consistency;
- places where the educational wording may imply more certainty than the literature supports.

## What this project is not

Please do not submit changes that turn this handbook into:

- a new Hubble tension solution proposal;
- a claim that Lambda-CDM is definitively overturned;
- a claim that any single observation has settled the full tension;
- an AI-discovered cosmology claim.

## Preferred correction format

When suggesting a correction, please include:

```text
File:
Section:
Current wording:
Problem:
Suggested replacement:
Reference:
Reason:
```

## Citation rule

Do not add a citation unless the source has been checked.

For new references, please include:

```text
BibTeX key:
Title:
Authors:
Year:
Journal / source:
DOI:
arXiv:
What claim it supports:
```
