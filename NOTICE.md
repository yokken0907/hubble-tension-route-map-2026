# Notice

## Claim boundary preservation

This project is an educational handbook and route map.

It does not claim to solve the Hubble tension.  
It does not propose a new cosmological model.  
It is not an expert-reviewed cosmological conclusion.

When quoting, translating, adapting, teaching, or discussing this material, please preserve that claim boundary.

## AI-use transparency

Generative AI was used as an auxiliary tool for structuring, drafting, terminology organization, comparison-table preparation, QA scaffolding, and claim-boundary checking.

AI-generated text is not treated as scientific evidence.

Scientific claims require verified literature, observational data, reproducible analysis, and expert scrutiny.

## Public-review status

This version is GitHub-ready as a public review candidate, not as a final educational release.

Corrections are welcome, especially on:

- inaccurate cosmology statements,
- outdated observational status,
- missing references,
- misleading simplifications,
- citation placement,
- terminology consistency.
